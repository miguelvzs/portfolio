Migrando o Hub de RH para o Google Cloud

Miguel Vaz · setembro de 2026

Na Enviagora, uso o Google Cloud com Terraform em todos os projetos e conduzi a migração do Hub de RH para ele. Este texto resume como essa migração foi feita.

O destino, em Terraform

Toda a infraestrutura nova é declarada em Terraform:

  • Cloud Run para rodar os serviços.
  • Cloud SQL (PostgreSQL) com IP privado.
  • Secret Manager para os segredos.
  • Load Balancer e Cloud DNS na frente.

Deploy sem chave e com aprovação

O CI/CD roda no GitHub Actions e se autentica no Google Cloud por Workload Identity Federation, sem chave de conta de serviço. O pipeline tem secret scanning, e o deploy em produção só sai com aprovação.

A virada

  1. Ensaio em QA: a migração inteira roda antes num ambiente de QA.
  2. Validação: os dados migrados são conferidos por contagem e checksum.
  3. Cutover: a virada em produção levou cerca de 45 minutos, com rollback pronto.

Hoje faço parte do time que constrói o EnviaMind, a plataforma única da empresa.
